# 🌿 먹이 피라미드 시뮬레이터

풀 → 토끼 → 여우 → 매로 이어지는 먹이 피라미드를 실시간으로 관찰하고
직접 지형을 편집할 수 있는 픽셀아트 생태계 시뮬레이터입니다.
순수 HTML/CSS/JS(캔버스)로만 만들어져 별도 빌드 없이 GitHub Pages에서 바로 동작합니다.

## 기능

- **지형 편집 도구**: 🌱 풀 심기 / 🟫 맨땅 만들기 / 💧 강 그리기 / 🔥 발화 / 🧽 생명 지우개
- **생명체 배치**: 🐇 토끼, 🦊 여우, 🦅 매를 원하는 위치에 직접 추가
- **강 자동 생성**: "강 생성" 버튼으로 구불구불한 새 강을 지형에 새겨넣기
- **산불 시뮬레이션**: 풀(연료량)에 따라 확산되며, 불탄 땅은 시간이 지나야 다시 풀이 자람
- **배속 조절**: 일시정지 / 1x / 2x / 4x / 8x
- **실시간 그래프**: 토끼·여우·매 개체수와 평균 풀 밀도를 추적
- **조절 슬라이더**: 풀 재생 속도, 브러시 크기, 산불 확산 속도

## 색상 규칙

- 밝은 초록색 = 풀이 무성한 땅
- 어두운 초록색 = 풀이 없는 땅
- 검은색 = 불에 타서 그을린 땅
- 파란색 = 강(물)

## 로컬 실행

빌드 과정이 없으므로 `index.html`을 정적 서버로 열기만 하면 됩니다.

```bash
npx serve .
# 또는
python3 -m http.server 8080
```

## GitHub Pages 배포

`.github/workflows/deploy-pages.yml` 워크플로가 `main` 브랜치로 푸시될 때마다
자동으로 GitHub Actions를 통해 Pages에 배포합니다.

최초 1회, 저장소 **Settings → Pages → Build and deployment → Source**를
**GitHub Actions**로 설정해야 합니다 (이미 설정되어 있다면 별도 작업 불필요).
